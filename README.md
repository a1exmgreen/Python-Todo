# Python tkinter todo app
A desktop application built with Python and Tkinter.

The project is being developed as a practical learning exercise to practise:
- Python
- Tkinter GUI development
- Working with multiple Python modules
- File storage
- Git and Github

# Current features
- Sidebar navigation
- Today's date
- Task list
- Task checkboxes
- Seperate modules for the sidebar and tasks
- Add new tasks
- Save tasks between sessions
- Mark tasks as completed

# Planned features
- Delete and edit tasks
- Tasks due dates
- Task priorities
- Routines, events and checklists
